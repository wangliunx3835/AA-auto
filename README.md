# AADisplay 双模式：Android Auto / CarPlay

以 android-carplay 为主包，合并独立 AA-auto 引擎。首页顶部选择 Android Auto 或 CarPlay，保留两种模式各自的设置页、双虚拟屏和悬浮媒体功能。切换时会断开当前投屏并重启应用进程，**无需重启手机系统**。

当前发布版本：**V78**，用户已于 2026-11-07 实车确认连接问题修复。修复新配对车机因 AA 服务缓存未更新而不出现在列表的问题。已配对设备均可手动选择，自动连接仍只针对已确认 AA 服务且蓝牙已连接的车机。保留 V77 协议字段保护、V75 不闪屏修复。详见 [V78 发布说明](https://github.com/wangliunx3835/AA-auto/releases/tag/v78)。

## 安装

1. Android 13+、ARM64 手机，已 Root 并安装兼容的 LSPosed。
2. 本次 V78 使用新签名：先记录设置并备份私人证书，再卸载旧版、安装新版。打开 LSPosed 重新启用本模块，勾选系统框架。沿用当前合并版已经正常工作的作用域；勿同时启用旧的独立投屏模块，以免争用。
3. 首次启用模块或系统桥检查提示版本不匹配时，重启手机一次。日常模式切换不需重启。本次卸载重装后建议重启一次以重新加载模块。已安装本次 V78 新签名版的用户无需重装。
4. 打开应用，检查 Root、模块及桥接状态，按界面授予附近设备、通知等实际请求的权限。

## Android Auto 无线连接

- 首页选择 Android Auto，使用支持无线 AA 的车机。
- 在系统蓝牙中完成与车机配对，返回应用点击“授权并刷新无线车机”，选择已配对车机连接。
- 若提示手机证书被拒绝，在手机证书区域按界面导入 APK/APKM 或两个 PEM 文件。源码中的合成测试证书不能用于连接。
- 保留当前已正常工作的画面参数，先用同样的分辨率和帧率比较旧版与 V78；降低帧率并不是本次闪屏修复方案。

## CarPlay 连接

首页选择 CarPlay，按原有已正常工作的车机配对方式连接。不同车机的配对方向和发现方式可能不同，优先沿用现有配对记录。合并版保留 CarPlay 稳定连接逻辑；手机端强制静音及其定时任务已取消，声音优先走已有路由，复制采集回退时可能手机与车机同时出声。

## 分屏与切换

使用分隔条调整比例、全屏/恢复分屏、交换左右应用；应用列表、最近任务、输入法和悬浮媒体沿用各自模式的界面。模式切换会中断当前连接，请等待旧模式退出后再连接新模式。

## 日志与性能比较

- 点击“导出诊断 ZIP”保存连接、桌面状态及 app-memory.txt 应用进程内存快照。
- 需要排查画面时点击“手动抓取 5 秒画面”，结束后再导出。V76 不再抓取 GPU PNG 截图，保留编码与发送记录。
- 诊断视频包含屏幕内容，请检查后再分享；不要把私人证书或密钥提交到仓库。
- 内存比较需保持投屏应用、分屏、分辨率、连接时长一致。应用 PSS 与系统界面的进程组占用口径可能不同。
